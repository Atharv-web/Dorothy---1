# Dorothy ingestion layer

This is where documents enter Dorothy. Upload files, select a folder, or add a ZIP or RAR archive, and the app extracts their text and tables into readable Markdown and structured JSON.

It handles PDFs, Word documents, spreadsheets, presentations, plain text, and images, including scanned pages. You can follow each upload's progress, preview the extracted content, and download the results. Files that cannot be read are listed with an explanation.

Processing runs locally, and uploads and results are saved so you can return to them later.
